Triage: duplicate reports

owner support desk accepted reviewed 2026-10-28 · 0 days ago

A busy morning brings hundreds of reports about the same thing. We keep one ticket per issue and merge every duplicate into it, so engineering sees one thread with a count.

The rule

A report is a duplicate when the underlying cause matches an open ticket. Decision 0002 supersedes the old subject-only rule:

  1. read the body and identify the tenant, its locale, form version and channel;
  2. compare the cause with existing tickets, using the rendered views and source logic;
  3. merge only with matching cause evidence; otherwise keep separate for investigation.
Equal subjects can hide different causes. Different subjects can report the same cause. Browser locale and intake tags are not the tenant directory.
